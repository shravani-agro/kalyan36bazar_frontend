# kalyan36bazar Admin Console

Secure gaming operations console for kalyan36bazar.

## Tech Stack
- Vite
- React
- Tailwind CSS
- Shadcn UI
- Lucide Icons
- Sonner
- LocalStorage Mock API (Decoupled from Supabase)

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Default credentials: `admin` / `admin`
